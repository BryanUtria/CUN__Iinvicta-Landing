# Landing Page: INVICTA I-TECH 006 ⌚

Proyecto desarrollado como parte de la estrategia de Marketing Digital para el lanzamiento del smartwatch híbrido **INVICTA I-TECH 006** enfocado en el "Caminante Consciente". 

Este proyecto fue creado para la **Especialización En Gestión de Negocios Digitales (CUN)** - Mercadeo Digital.

## 🚀 Sobre el Proyecto (Uso)
Esta *landing page* está diseñada para captar *leads* calificados interesados en el bienestar y la tecnología híbrida. 
Cuenta con:
- Diseño premium enfocado en la dualidad estética (deportivo/elegante).
- Carrusel dinámico de imágenes del producto.
- Simulación de un carrito de compras interactivo para medir la intención de venta.
- Formulario de captación de leads (Nombre, Correo, Teléfono) para un sorteo promocional y entrega de códigos de descuento.

## 🛠️ Programas Requeridos
Al ser un proyecto estático construido con estándares web puros (HTML5, CSS3, Vanilla JavaScript), **no requiere la instalación de librerías ni frameworks pesados**. Solo necesitas:
1. **Un Navegador Web moderno** (Google Chrome, Firefox, Edge, Safari).
2. **Opcional pero recomendado:** Un editor de código como [Visual Studio Code (VS Code)](https://code.visualstudio.com/) si deseas modificar el contenido.

## 💻 Cómo ejecutarlo localmente
Existen dos formas muy sencillas de visualizarlo en tu computadora:

**Opción 1: Directo en el navegador (La más fácil)**
1. Abre la carpeta del proyecto en el explorador de archivos de tu computadora.
2. Haz doble clic sobre el archivo `index.html`. 
3. La página se abrirá inmediatamente en tu navegador predeterminado y estará lista para ser utilizada.

**Opción 2: Usando un Servidor Local (Recomendado)**
1. Abre el proyecto en **Visual Studio Code**.
2. Ve a la sección de extensiones, busca **"Live Server"** (de Ritwick Dey) e instálala.
3. Haz clic derecho sobre el archivo `index.html` en tu lista de archivos y selecciona **"Open with Live Server"**.
4. Se abrirá automáticamente una ventana del navegador conectada a un servidor local (normalmente en la dirección `http://127.0.0.1:5500`).

## 🛑 Cómo detenerlo (Apagar el proyecto)
- **Si usaste la Opción 1:** Simplemente cierra la pestaña del navegador donde abriste el archivo.
- **Si usaste la Opción 2 (Live Server):** Ve a la barra inferior azul de Visual Studio Code y haz clic en el ícono de **"Port: 5500"** para detener el servidor local. Luego, puedes cerrar la pestaña de tu navegador.

## 🌐 Cómo Desplegarlo (Lanzarlo a Producción en GitHub Pages)
La forma más sencilla y **gratuita** de tener tu web en internet bajo una URL pública es utilizando **GitHub Pages**:

1. **Sube tu código a GitHub:**
   - Inicia sesión en tu cuenta de GitHub y crea un nuevo repositorio público (por ejemplo, llámalo `invicta-landing`).
   - Sube el contenido **interno** de esta carpeta (`index.html`, `style.css`, `script.js`, este archivo `README.md` y la carpeta `images`).
2. **Activa el alojamiento gratuito:**
   - Una vez subidos los archivos, ve a la pestaña **Settings** (Configuración) de tu repositorio.
   - En el menú lateral izquierdo, haz clic en **Pages**.
   - Bajo la sección "Build and deployment", busca el campo desplegable que dice "Branch" (Rama). Cámbialo de *None* a **main** (o master) y presiona "Save" (Guardar).
3. **¡Tu web está lista!**
   - En la parte superior de esa misma sección de "Pages", aparecerá un mensaje indicando que tu sitio está en vivo. Copia ese enlace (ej. `https://tu-usuario.github.io/invicta-landing/`) y compártelo. *(Nota: a veces GitHub tarda un par de minutos en habilitar el enlace la primera vez).*
